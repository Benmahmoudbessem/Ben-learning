BEN-LEARNING V2.7 — CONFIGURATION FIREBASE OBLIGATOIRE
======================================================

Cette version ajoute :
- Validation des inscriptions (pending / approved / rejected)
- Chat élève ↔ administration
- Notifications Firebase

1) FIREBASE AUTHENTICATION
--------------------------
Firebase Console > Authentication > Sign-in method > Email/Password > Activer.

2) FIRESTORE DATABASE
---------------------
Firebase Console > Firestore Database > Rules.

IMPORTANT : remplace les anciennes règles par le contenu COMPLET du fichier :
firestore.rules

Puis clique sur PUBLISH / PUBLIER.

Sans ces nouvelles règles :
- l'Admin ne pourra pas accepter/refuser les inscriptions ;
- le chat ne fonctionnera pas ;
- les notifications ne fonctionneront pas.

3) COMPTE ADMIN
---------------
Ton compte Admin doit exister dans :
Firestore > users > TON_UID

Le champ doit être :
role = "admin"

Le statut du compte Admin n'est pas utilisé pour l'accès admin.

4) NOUVELLE INSCRIPTION
-----------------------
Un nouvel élève reçoit automatiquement :
role = "student"
status = "pending"

Il peut se connecter mais il NE PEUT PAS ouvrir les cours ni les quiz.
Il voit la page status.html et peut utiliser le chat/notifications.

5) VALIDATION PAR L'ADMIN
-------------------------
Admin > Gestion des inscriptions :
- Accepter -> status = "approved"
- Refuser  -> status = "rejected"

Une notification est créée automatiquement pour l'élève.

6) ANCIENS COMPTES
------------------
Les comptes créés avec les versions précédentes peuvent avoir :
status = "active"

Dans V2.7, ils seront considérés comme non validés jusqu'à ce que l'Admin
clique sur "Accepter" dans le tableau des inscriptions.

7) COLLECTIONS CRÉÉES AUTOMATIQUEMENT
--------------------------------------
users
chatMessages
notifications

Tu ne dois pas créer ces collections manuellement.
