BEN-LEARNING V4.1 — CONFIGURATION FIREBASE
==========================================

1) AUTHENTICATION
Firebase Console > Authentication > Sign-in method > Email/Password > Activer.

2) VÉRIFICATION EMAIL
Aucune option supplémentaire n'est nécessaire dans le code :
Ben-Learning appelle Firebase sendEmailVerification().
Lors d'une inscription :
- compte créé
- email de vérification envoyé
- l'élève clique sur le lien
- retour sur status.html
- bouton "J'ai vérifié mon email"
- emailVerified passe à true dans Firestore

3) FIRESTORE RULES
Firebase Console > Firestore Database > Rules.
Remplace TOUTES les règles par le contenu du fichier firestore.rules puis clique PUBLIER.

Les règles V4.1 bloquent :
- les cours / quiz / devoirs / séances si l'email n'est pas vérifié ;
- l'acceptation Admin si emailVerified n'est pas true.

4) COMPTE ADMIN
Dans Firestore > users > TON_UID :
role = "admin"

5) INSCRIPTIONS
Nouveau compte :
role = "student"
status = "pending"
emailVerified = false

Après clic sur le lien de vérification :
emailVerified = true

Admin > Validation des inscriptions :
le bouton "Accepter" est désactivé tant que l'email n'est pas vérifié.

6) ANCIENS ÉLÈVES
Ils doivent se connecter, aller sur la page de statut, cliquer "Renvoyer l'email",
vérifier leur boîte mail puis cliquer "J'ai vérifié mon email".

7) COLLECTIONS
users
courses
sessions
homework
homeworkSubmissions
chatMessages
notifications
courseProgress
quizResults

8) DÉPLOIEMENT
Après mise à jour des règles Firestore :
git add .
git commit -m "Ben-Learning V4.1 email verification"
git push origin main
